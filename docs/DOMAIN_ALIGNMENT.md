# Petroleum engineering domain alignment

| Technical area | LogLens relevance | Relevant keywords |
|---|---|---|
| Wireline logging and formation evaluation | Primary | Wireline logs, formation evaluation, lithology interpretation |
| Subsurface data analytics and interpretation software | Primary | Subsurface data analytics, interpretation workflows, ML decision support |
| Drilling analytics | Adjacent | Drilling-related ROP curve when present; not the main function |
| Drilling fluids | Indirect | Mud weight / drilling-fluid curve only if present in source data |
| Integrated subsurface workflows and technical evaluation | Adjacent | Integrated subsurface workflow, technical evaluation |

LogLens does not implement every area listed. Its current functionality is log-based lithofacies classification; the other areas are listed only to show where the engineering task connects to wider petroleum-engineering practice.

LogLens is an independent student research prototype developed for educational and research purposes. It is a machine-learning-based lithofacies classification and decision-support application, not a commercial-grade petrophysical interpretation system.
